# 0.52.0 — download queue and collections rail

- **#40** `move_to_front(id, kind?)` callable (ROM and firmware); `get_download_queue` lists in position order; the
  queue UI gets **Start now** (move to front, pause the running transfer, resume if stopped), and speed + time left
  measured client-side from the progress byte counts (`utils/downloadSpeed.ts`). Queue state after reopening comes
  from the ordered backend list.
- **#28** `resume_unreachable_interrupted` runs every 30 s in the backend and resumes jobs interrupted with
  `server_unreachable` / `timeout` in queue order (not `auth_failed`, `disk_full`, `needs_recovery`).
- **Collections rail:** the Library tab lists this device's `RomM: [Name] (host)` Steam collections under the
  platforms; choosing one narrows the grid by app id (`utils/romCollections.ts`, `GridQuery.collection`).
