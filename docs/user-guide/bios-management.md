# Switch firmware and keys

Nintendo Switch emulators (Eden, yuzu, Ryujinx) need your console's **keys** to run most games, and a **firmware**
archive for some of them. If you keep those files on your RomM server (in its `bios/Switch` folder), the plugin can
check them against what is on this machine and put the missing ones in place.

Everything lives in the **Systems & BIOS** tab of the RomM Library (Quick Access Menu → **Open RomM Library**, then **L1** / **R1**). **B** leaves the library. A game's own page also shows the keys it needs in its **BIOS & Core** tab.

> Switch only for now. Other systems' BIOS files return in later versions (see `REMOVED_TILL_0_90_0.md`).

## What the plugin looks at

**Keys.** Each emulator reads keys from its own folder, not from `Emulation/bios`:

| Emulator | Keys folder                  |
| -------- | ---------------------------- |
| Eden     | `~/.local/share/eden/keys/`  |
| yuzu     | `~/.local/share/yuzu/keys/`  |
| Ryujinx  | `~/.config/Ryujinx/system/`  |

| File             | Needed by            | Required |
| ---------------- | -------------------- | -------- |
| `prod.keys`      | Eden, yuzu, Ryujinx  | yes      |
| `title.keys`     | Eden, yuzu, Ryujinx  | yes      |
| `console.keys`   | Ryujinx              | optional |
| `key_retail.bin` | Ryujinx              | optional |

Only emulators that are installed are listed. The emulators' own files (for example `title.keys_autogenerated`) are
never touched.

**Firmware.** RomM may host several firmware versions as `Firmware.<version>.zip`. The plugin saves the one you choose
to `Emulation/bios/switch/` and does **not** install it for you: you install it from the emulator's own
*Install Firmware* menu.

## Reading the key list

For every key file and installed emulator the Systems & BIOS tab shows one of:

- **matches RomM** — the file on this machine is the same as RomM's.
- **missing** — the emulator has no such file.
- **differs from RomM — kept as is** — you have your own file with other contents. The plugin leaves it alone.
- **present** — a file exists, but there is nothing to compare it with (RomM is unreachable, or RomM reports no
  checksum).

If RomM is offline the page shows what it can from this machine and says so; downloads are unavailable until RomM is
back.

## Choosing the firmware version

The **Firmware version** dropdown offers *Newest available* (the default, follows RomM) and every version RomM has.
The choice is saved. If RomM later no longer has the version you chose, the plugin falls back to the newest.

## Downloading

- **Download Required** fetches the missing `prod.keys` and `title.keys` and the firmware version you chose.
- **Download All** also fetches the optional Ryujinx keys.

The downloads go into the normal **Downloads** list, so you can pause, resume, cancel and reorder them like game
downloads, and they continue after a restart. Each file is checked against RomM's checksum before it is installed: a
file that does not match is discarded and nothing is installed. A key file goes to the first emulator that lacks it and
is copied to every other installed emulator that lacks it. **The plugin never overwrites a file you already have.**
When a key file differs from RomM's, the answer says so ("kept your own prod.keys").

## Replacing a key with RomM's

If you do want RomM's copy instead of your own, press **Replace *Emulator*'s *file* with RomM's** next to the file.
The plugin asks first. When you confirm it downloads RomM's file, checks its checksum, moves your file aside as
`prod.keys.romm-backup` (`.romm-backup.1`, `.2`, … if you replace again — an earlier backup is never overwritten) and
puts RomM's file in place. If anything fails, your file stays where it was. To go back, rename the backup.

## Troubleshooting

- **"No Switch emulator found"** — install Eden, yuzu or Ryujinx with EmuDeck first; only installed emulators get keys.
- **A key shows "differs" but the game runs** — your own file is fine; leave it, or replace it only if you prefer RomM's.
- **"RomM has no Switch firmware"** — upload the files to RomM's `bios/Switch` folder, then reopen the page.
- **A download failed with a checksum message** — RomM's file may be damaged or changed during the transfer; try again,
  and if it keeps failing, check the file on the RomM server.
- **Where is the firmware?** `Emulation/bios/switch/Firmware.<version>.zip` (the page shows the folder). Install it from
  the emulator's menu; the plugin cannot do that part.
